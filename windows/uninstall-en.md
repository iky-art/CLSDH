# 🗑️ Uninstall CLSDH from Windows (English)

> How to remove CLSDH from Windows.

---

## 🗑️ Steps (WSL)

```bash
cd ~/CLSDH
rm -f clsdh
cd ..
rm -rf CLSDH
```

## 🗑️ Steps (MinGW)
Delete `clsdh.exe` and CLSDH folder.
