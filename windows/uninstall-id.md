# 🗑️ Uninstall CLSDH dari Windows (Bahasa Indonesia)

> Cara menghapus CLSDH dari Windows.

---

## 🗑️ Langkah (WSL)

```bash
cd ~/CLSDH
rm -f clsdh
cd ..
rm -rf CLSDH
```

## 🗑️ Langkah (MinGW)
Hapus file `clsdh.exe` dan folder CLSDH.

---

> 🇮🇩 Bahasa Indonesia. Versi Inggris tersedia di `windows/uninstall-en.md`.
