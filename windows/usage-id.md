# 📋 Panduan Penggunaan CLSDH di Windows (Bahasa Indonesia)

> Panduan menjalankan CLSDH di Windows (WSL / Git Bash).

---

## 🔗 Link Check
```bash
./clsdh link-check https://example.com --concurrency 10
```

## 🔌 Port Check
```bash
./clsdh tcp-port google.com 443
./clsdh udp-port 8.8.8.8 53
```

## 🖥️ Monitor Sistem
```bash
./clsdh cpu-monitor
./clsdh mem-monitor
./clsdh disk-monitor /
./clsdh net-stats
```

## 📁 File & Utilitas
```bash
./clsdh md5 "clsdh"
./clsdh sha256 "clsdh"
./clsdh uuid
./clsdh password-gen 16
```
