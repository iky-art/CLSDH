# 🚀 Advanced CLSDH Guide on Windows (English)

> Advanced tips for Windows users.

---

## ⚡ Run in Background (WSL)
```bash
nohup ./clsdh net-stats > ~/net.log 2>&1 &
```

## 🔐 Low Port Access
```bash
sudo ./clsdh port-scan localhost 1 100
```
