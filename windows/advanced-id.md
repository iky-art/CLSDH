# 🚀 Panduan Lanjut CLSDH di Windows (Bahasa Indonesia)

> Tips lanjut untuk pengguna Windows.

---

## ⚡ Jalankan di Background (WSL)
```bash
nohup ./clsdh net-stats > ~/net.log 2>&1 &
```

## 🔐 Akses Port Rendah
```bash
sudo ./clsdh port-scan localhost 1 100
```
