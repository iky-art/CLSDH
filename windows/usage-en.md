# 📋 CLSDH Usage Guide on Windows (English)

> Guide to run CLSDH on Windows (WSL / Git Bash).

---

## 🔗 Link Check
```bash
./clsdh link-check https://example.com --concurrency 10
```

## 🔌 Port Check
```bash
./clsdh tcp-port google.com 443
./clsdh udp-port 8.8.8.8 53
```

## 🖥️ System Monitor
```bash
./clsdh cpu-monitor
./clsdh mem-monitor
./clsdh disk-monitor /
./clsdh net-stats
```

## 📁 File & Utilities
```bash
./clsdh md5 "clsdh"
./clsdh sha256 "clsdh"
./clsdh uuid
./clsdh password-gen 16
```
