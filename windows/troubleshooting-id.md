# 🔧 Troubleshooting CLSDH di Windows (Bahasa Indonesia)

> Masalah umum dan solusi di Windows.

---

## ❌ "g++: command not found"
Pastikan WSL2 atau MinGW-w64 terinstal dan ditambahkan ke PATH.

## ❌ "Permission denied"
```bash
chmod +x clsdh
```

## ❌ WSL tidak ditemukan
```powershell
wsl --install
```
