# 🔧 CLSDH Troubleshooting on Windows (English)

> Common issues and solutions on Windows.

---

## ❌ "g++: command not found"
Make sure WSL2 or MinGW-w64 is installed and added to PATH.

## ❌ "Permission denied"
```bash
chmod +x clsdh
```

## ❌ WSL not found
```powershell
wsl --install
```
