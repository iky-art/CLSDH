# 📝 Changelog CLSDH

Semua perubahan penting pada proyek CLSDH akan dicatat dalam file ini.

---

## [2.0.0] - 2026-11-14

### 🎉 Ditambahkan
- 49 tools dalam satu binary CLI
- ASCII art custom CLSDH dengan warna magenta `#ff00ff`
- Dukungan multi-platform: Linux, macOS, Windows, Termux
- Output real-time dengan timestamp
- Auto-update (`./clsdh upd`)
- Simpan hasil ke file (`-o` / `--output`)
- Mode tanpa warna (`--no-color`)
- Dokumentasi lengkap dalam Bahasa Indonesia dan Inggris
- Folder `doc/`, `termux/`, `macos/`, `windows/`, `linux/`

### 🛠️ Diperbaiki
- Perbaiki parsing warna ANSI pada ternary operator
- Perbaiki tipe pointer DNS untuk IPv4/IPv6
- Perbaiki variabel yang bentrok pada cpu-monitor
- Tambahkan header `<sys/statfs.h>` untuk disk-monitor
