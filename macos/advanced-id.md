# 🚀 Panduan Lanjut CLSDH di macOS (Bahasa Indonesia)

> Tips lanjut untuk pengguna macOS.

---

## ⚡ Jalankan di Background
```bash
nohup ./clsdh net-stats > ~/net.log 2>&1 &
```

## 🔐 Akses Port Rendah
```bash
sudo ./clsdh port-scan localhost 1 100
```
