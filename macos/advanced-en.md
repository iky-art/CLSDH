# 🚀 Advanced CLSDH Guide on macOS (English)

## ⚡ Run in Background
```bash
nohup ./clsdh net-stats > ~/net.log 2>&1 &
```

## 🔐 Low Port Access
```bash
sudo ./clsdh port-scan localhost 1 100
```
