# 📦 CLSDH Dependencies on macOS (English)

> List of required packages on macOS.

---

## 📋 Required Packages

| Package | Function | Install Command |
|---------|----------|-----------------|
| `gcc` / `clang` | C++ Compiler | `brew install gcc` |
| `git` | Version control | `brew install git` |
| `make` | Build tools | `brew install make` |

---

## 🔧 Optional

| Package | Function | Install Command |
|---------|----------|-----------------|
| `openssl` | SSL/TLS support | `brew install openssl` |
| `whois` | WHOIS lookup | `brew install whois` |
| `ping-utils` | Ping command | `brew install ping` |
