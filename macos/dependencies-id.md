# 📦 Dependensi CLSDH di macOS (Bahasa Indonesia)

> Daftar paket yang diperlukan di macOS.

---

## 📋 Paket Wajib

| Paket | Fungsi | Cara Instal |
|-------|--------|-------------|
| `gcc` / `clang` | Compiler C++ | `brew install gcc` |
| `git` | Version control | `brew install git` |
| `make` | Build tools | `brew install make` |

---

## 🔧 Opsional

| Paket | Fungsi | Cara Instal |
|-------|--------|-------------|
| `openssl` | Dukungan SSL/TLS | `brew install openssl` |
| `whois` | WHOIS lookup | `brew install whois` |
| `ping-utils` | Ping command | `brew install ping` |
