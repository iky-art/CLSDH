# 🗑️ Uninstall CLSDH from Termux (English)

> How to remove CLSDH from Android device.

---

## 🗑️ Uninstall Steps

1. Go to CLSDH folder:
   ```bash
   cd ~/CLSDH
   ```

2. Remove binary and folder:
   ```bash
   rm -f clsdh
   cd ..
   rm -rf CLSDH
   ```

3. Or directly remove folder:
   ```bash
   rm -rf ~/CLSDH
   ```

---

## 🧹 Clean Cache (Optional)

```bash
pkg clean
```
