# 🤝 Kontribusi CLSDH

Terima kasih telah berminat berkontribusi pada CLSDH! Berikut panduan untuk berkontribusi.

---

## 📋 Cara Berkontribusi

1. **Fork** repository ini
2. **Buat branch** baru: `git checkout -b fitur/nama-fitur`
3. **Lakukan perubahan** pada kode atau dokumentasi
4. **Commit** perubahan: `git commit -m "feat: deskripsi perubahan"`
5. **Push** ke branch: `git push origin fitur/nama-fitur`
6. **Buat Pull Request**

---

## 🛠️ Standar Kode

- Gunakan **C++11** atau lebih baru
- Komentar dalam bahasa **Indonesia** atau **Inggris**
- Gunakan spasi 4 untuk indentasi
- Pastikan kode dapat dikompilasi dengan `g++ -std=c++11 -O2 -pthread`

---

## 📝 Format Commit

Gunakan format conventional commits:

```
feat: tambahkan tool baru
fix: perbaiki bug pada tcp-port
docs: perbarui README.md
```
