# 📦 CLSDH Dependencies on Linux (English)

> List of required packages on Linux.

---

## 📋 Required Packages

| Distro | Packages | Command |
|--------|----------|---------|
| Ubuntu/Debian | `g++`, `git`, `make` | `sudo apt install g++ git make` |
| CentOS/RHEL | `gcc-c++`, `git`, `make` | `sudo dnf install gcc-c++ git make` |
| Arch | `gcc`, `git`, `make` | `sudo pacman -S gcc git make` |

---

## 🔧 Optional

| Package | Function |
|---------|----------|
| `openssl` | SSL/TLS support |
| `whois` | WHOIS lookup |
| `iproute2` | `ip` command |
