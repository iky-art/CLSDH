# 📦 Dependensi CLSDH di Linux (Bahasa Indonesia)

> Daftar paket yang diperlukan di Linux.

---

## 📋 Paket Wajib

| Distro | Paket | Perintah |
|--------|-------|----------|
| Ubuntu/Debian | `g++`, `git`, `make` | `sudo apt install g++ git make` |
| CentOS/RHEL | `gcc-c++`, `git`, `make` | `sudo dnf install gcc-c++ git make` |
| Arch | `gcc`, `git`, `make` | `sudo pacman -S gcc git make` |

---

## 🔧 Opsional

| Paket | Fungsi |
|-------|--------|
| `openssl` | Dukungan SSL/TLS |
| `whois` | WHOIS lookup |
| `iproute2` | Perintah `ip` |
